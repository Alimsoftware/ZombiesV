# ZombiesMod

Projeto de modificação para GTA V – ZombiesMod.

## Objetivo

Adicionar itens/props e funcionalidades personalizadas ao jogo.

## Estrutura

```
├─ src/                # Código‑fonte (C#)
├─ assets/             # Texturas, modelos, etc.
├─ data/               # Arquivo JSON de itens: ZombiesMod_CustomItems.json
├─ logs/               # Log de erros: errors.log
└─ README.md
```

## Como usar

1. Clone o repo.
2. Compile o projeto (ex.: `dotnet build`).
3. Inicie GTA V e carregue o mod.
